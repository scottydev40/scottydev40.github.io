Scotty

Native Google Quick Share for Linux.

Send and receive files with nearby Android and ChromeOS devices, using the sharing that is already built into them. No app on the other device, no account, no cloud.

What sets it apart: transfers work even with no shared Wi-Fi, and even with the phone's Wi-Fi switched off. Scotty reaches the phone over Bluetooth, opens a direct link, moves the files, and leaves your internet connection untouched throughout.

Install with Flatpak

  1. Add the repository 
    flatpak remote-add --if-not-exists scotty \
  https://scottydev40.github.io/scotty.flatpakrepo
  2. Install 
    flatpak install scotty dev.scotty.Scotty
  3. Run 
    flatpak run dev.scotty.Scotty

Updates arrive automatically through flatpak update. The KDE runtime comes from Flathub, so set that up first if you have not. A self-updating AppImage is on the releases page if you prefer a single file.
